# Workspace identity badges

Approved reference for [issue #394](https://github.com/Vinosaamaa/interview-arc/issues/394).
The board is design evidence, not a pixel-perfect production screenshot.

## Direction

Interview Arc already has one centered text switcher in the 50px application
bar. The left rail still introduced the active workspace as stacked type
(`INTERVIEW` / `Workspace`) and leftover letter tiles (`I`, `L`, `E`). Those
marks read as a generic dashboard avatar row.

The replacement is a shared family of **mineral specimen plates**:

- one 28×28 chamfered tile per workspace (Interview Arc’s clipped-corner
  vernacular, not a Notion letter square);
- three distinct two-stroke motifs: a practice arc, a lesson folio, and an
  evidence facet;
- pigment from the existing shell accents (teal `#0D9488`, cobalt `#315CA8`,
  ember `#D86742`) on the mineral canvas;
- selected state lives on the plate itself;
- `Later` is a quiet unavailable status, never a second title.

The 980px destination dock and Career Materials `CM` glyph are out of scope.
