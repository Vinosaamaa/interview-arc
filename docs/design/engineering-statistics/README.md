# Engineering Statistics mockup

Standalone HTML for [Arc issue #395](https://github.com/Vinosaamaa/interview-arc/issues/395). It redesigns Engineering Statistics in Journal’s three-panel workbench language (hero, index, reader, evidence desk) using the mineral canvas and rust/teal accents already in Engineering.

This is a visual proposal. Production `EngineeringStatistics` is unchanged until the owner reviews it.

## Open

From a clone, open the file in a browser. No app auth:

`docs/design/engineering-statistics/index.html`

Numbers, refs, commits, and pull-request labels on the page are invented sample projection data.

Review previews (not production UI):

- `preview-records.png` — destination hero and workbench
- `preview-workbench.png` — rich-record index, reader, and evidence desk
- `preview-receipts.png` — All merged PRs layer
- `preview-receipt-chronology.png` — survey-staff chronology
- `preview-mobile.png` — compact viewport

## What it keeps

Every current Statistics fact: record counts, effective status, classification, repositories, chronology, and receipt completeness (projected receipts, complete merge facts, reconstructed, missing facts). It does not add mastery or productivity scores.
