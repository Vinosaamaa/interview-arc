# Learn Materials

Use Arc's paper, mineral, deep teal and editorial type. Add Materials to Learn's
existing destination navigation. A narrow source index and broad reading page
keep long explanations readable; on phones a selected material occupies the
full reading width, with a clear return to the index.

Order: source identity and private status; detailed overview; linked topic
outline; substantial topic sections with source locations; important notes;
collapsed full transcript/original. Warnings about incomplete reading precede
the summary. A summary is a separate interpretation, never a replacement file.

Source disclosure preserves the original download and safely renders HTML,
PDF and images where supported. Text fragments retain every character and
explicit loading progress; Load full source follows every part. Find searches
loaded text only and says so. No fabricated transcript, silent truncation,
rewriting of original source, fake play controls or generated hero art.

Self-review: the sidebar is an index rather than a card dashboard. Source
locations and coverage make the distinction between original and interpretation
visible. Keyboard-operable native details and controls, 44px targets, wrapping
text, 17px mobile prose and phone-width tests protect actual reading use.
