AI control plane

Proposal first. Apply second.

Approval is not a conversational implication. It is a single-use decision bound to an immutable proposal revision and content digest.

1 · Request

Owner intent plus minimum visible context.

2 · Draft

Schema-constrained model output with no tools.

3 · Normalize

References resolved server-side; warnings and unknowns recorded.

4 · Review

Owner sees the exact diff, sources, and consequences.

5 · Approve

Revision, digest, identity, expiry, and replay checks pass.

6 · Apply

Deterministic command returns a stable receipt or typed conflict.

Safe retry: approving or applying the same idempotency key returns the original receipt. It does not create a second Loop.

Edit means new approval: any owner correction creates a new digest. The prior approval can no longer authorize the changed payload.

Private evidence

An interview package, not a loose upload

A package groups related recordings and transcripts under one manifest, one Loop assignment, and a recoverable lifecycle.

A

Manifest

Loop, optional stage, interview time, file roles, and declared relationships are frozen before finalization.

B

Source integrity

Files stream through quarantine, type sniffing, size limits, SHA-256, and R2 readback before becoming ready.

C

Revision provenance

Supplied and generated transcripts remain separate revisions. Neither silently replaces the other.

draft→ uploading→ staged→ validating→ ready partial failed

What D1 owns

Package/asset metadata, checksums, statuses, transcript revisions, provenance, Loop and stage relationships, jobs, retention decisions, and deletion receipts.

What private R2 owns

Immutable source media bytes and, only when justified by measured size, large private derived bodies. Object keys are opaque and never exposed in public receipts.

Why existing practice audio is not reused
Current audio is scoped to a practice activity. A real hiring interview belongs to a Loop, can span stages and multiple files, and carries different retention, consent, provenance, and recovery semantics. Reusing the activity schema would hide that domain distinction and make later authorization harder to reason about.
How a local folder becomes a package
The browser builds a sanitized manifest from owner-selected files; it does not ingest an arbitrary machine path. Filenames are display metadata, not storage locations. No local absolute path, cookie, transcript excerpt, or private identifier enters GitHub, logs, or Engineering records.
What happens when only some files succeed
The package becomes partial. Usable assets remain visible, failed assets show safe retry actions, and the owner chooses whether to retry, finalize the usable subset, or delete the package. The system never pretends an incomplete set is complete.

Threat model

Private by construction

Prompt text, transcripts, recordings, names, local paths, owner IDs, object keys, and private record IDs are excluded from normal logs and public artifacts.

Prompt injection

Imported text is data, never instruction. Model output is schema-constrained and has no tools; references are resolved server-side.

Cross-owner access

Cloudflare Access identity supplies scope. Every D1 and R2 lookup enforces it and returns generic not-found behavior.

Replay

Single-use approval, exact digest, idempotency key, optimistic concurrency token, and durable command receipt.

Malformed media

Streaming limits, magic-byte detection, allowlisted formats, quarantine, checksums, and decompression limits.

Provider exposure

Minimum necessary payload, visible opt-in, replaceable adapter, retention policy, and no storage credentials.

Cost runaway

Per-owner quotas, pre-dispatch estimate, explicit retries, queue backpressure, and budget circuit breakers.

Owner gates

Decide these before private processing ships

Manual Loop creation can proceed independently; private media processing should wait for explicit data-policy choices.

Retain source audio indefinitely, for a fixed period, or only until an accepted transcript exists?
Which transcription/model provider and retention policy are acceptable for interview evidence?
Which assistant commands follow create_loop in the allowlist?
Do large transcript bodies stay in D1 or move to private R2 above a measured threshold?
Is speaker identification manual-only in the first release?
What are the maximum files, bytes, and recording duration per package?
Does v1 need an unassigned evidence inbox, or is Loop-first upload sufficient?
What cost estimate and budget trip should be visible before derived processing?
