# Review Queue Design Reference

The canonical approved presentation board is
[`interview-arc-review-queue-board.png`](interview-arc-review-queue-board.png).

It defines the intended visual and interaction direction for
[issue #115](https://github.com/Vinosaamaa/interview-arc/issues/115):

- the Recall Spine organizing **Review now**, **Review soon**, and **Later**;
- a fixed-height selection folio that bookmarks choices without moving rows;
- evidence-backed due reasons and previous-attempt actions;
- populated, filtered, empty, loading, selection, and component states;
- an editorial botanical visual language shaped with `frontend-design`.

The board is design evidence, not a pixel-perfect production screenshot.
Implementation must still satisfy the issue's authoritative data, responsive,
accessibility, motion, and verification requirements.
