# Interview Arc Terminal Wallpaper

[`interview-arc-terminal-wallpaper-4k.png`](interview-arc-terminal-wallpaper-4k.png)
is a 3840×2160 wallpaper for terminal-first Interview Arc practice.

The wallpaper translates the Review Queue's editorial-botanical direction into
a quiet coding surface:

- the Recall Spine remains at the far-left edge;
- the center is intentionally low-contrast and nearly empty;
- the wordmark and leaf establish identity without competing with code;
- warm parchment and pale sage support dark botanical terminal text.

Suggested terminal colors:

- foreground: `#18382E`;
- secondary text: `#53675D`;
- cursor/accent: `#A5B52E`;
- selection: `#DDE4D6` at an opacity appropriate to the terminal.

The source direction was created with `frontend-design`; the raster was
generated with the built-in image-generation tool and promoted to the required
4K project asset after visual inspection.
