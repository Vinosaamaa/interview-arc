# Reference preflight

1. Read the exact bank entry and canonical question URL.
2. For SystemDesign.io, inspect the current recommended-solution list and follow the most relevant accessible source links.
3. Prefer first-party engineering material, standards, and original technical documentation. Use reputable architecture articles when primary material is insufficient.
4. Record title, URL, and access date only for sources actually opened.
5. Do not bypass logins, subscriptions, or access controls. Do not copy third-party solutions into Interview Arc.
6. If a listed solution is unavailable or inadequate, disclose that before the mock and prepare an original design by triangulating prompt constraints and reliable technical references.

The reference set prepares the interviewer; it is not a script to reveal before the user's attempt.
