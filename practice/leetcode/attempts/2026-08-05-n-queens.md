 * Canonical URL: https://leetcode.com/problems/n-queens/
 *
 * Task: Place n queens on an n x n chessboard so that no two queens share a
 * row, column, or diagonal. Return every distinct arrangement as n strings;
 * 'Q' marks a queen and '.' marks an empty square. Arrangement order does not
 * matter. A queen attacks horizontally, vertically, and diagonally.
 *
 * Constraints: 1 <= n <= 9.
 *
 * Example n = 4 (one of two valid boards):
 *   . Q . .
 *   . . . Q
 *   Q . . .
 *   . . Q .
 * The row/column/diagonal relationships are the constraints; every row has
 * exactly one queen, and the two diagonals remain collision-free.
 * Example n = 1 -> [["Q"]].
 *
 * Java API: public List<List<String>> solveNQueens(int n).
 * Starter: use row-by-row backtracking with occupied-column and diagonal sets.
 */
class Solution {
    public List<List<String>> solveNQueens(int n) {
        int[] diag = new int[2*n], diagR = new int[2*n], col = new int[n];
        int[] res = new int[n];

        List<List<String>> ans = new ArrayList<>();

        backtrack(n, 0, diag, diagR, col, res, ans);
        return ans;
    }

     void backtrack(int n, int row, int[] diag, int[] diagR, int[] col, int[] res, List<List<String>> ans){

        if(row == n){
            ans.add(toResult(res));
            return;
        }

        for(int i=0; i<n; i++){
            if(col[i] !=0 || diag[row+i] != 0 || diagR[row-i + n] != 0) continue;

            col[i] = 1; diag[row+i] = 1; diagR[row-i+n] = 1;
            res[row] = i;
            backtrack(n, row+1, diag, diagR, col, res, ans);
            col[i] = 0; diag[row+i] = 0; diagR[row-i+n] = 0;
           // res[row] = 0;
        }
    }

    List<String> toResult(int[] res){
        List<String> tmp = new ArrayList<>();
        int n= res.length;
        for(int i=0; i<n; i++){
            StringBuilder sb =  new StringBuilder();

            for(int j = 0; j < n; j++){
                if(j != res[i]) sb.append(".");
                else sb.append("Q");
            }
            tmp.add(sb.toString());
        }
        return tmp;
    }
}

### Pattern recognition and constraints

The board must contain exactly one queen in every selected row, and no two queens may share a column or diagonal. Row-by-row construction removes row conflicts automatically; the remaining constraints can be represented by a column index, row - column, and row + column.

### Best approach

Backtrack one row at a time. For each column, skip it when the column, main diagonal, or anti-diagonal is occupied. Otherwise mark all three, recurse to the next row, and undo the marks. Materialize a board only after placing n queens.

```python
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        answer = []
        columns = set()
        main_diagonals = set()
        anti_diagonals = set()
        queen_column = [-1] * n

        def search(row: int) -> None:
            if row == n:
                board = []
                for column in queen_column:
                    board.append("." * column + "Q" + "." * (n - column - 1))
                answer.append(board)
                return

            for column in range(n):
                main = row - column
                anti = row + column
                if column in columns or main in main_diagonals or anti in anti_diagonals:
                    continue

                columns.add(column)
                main_diagonals.add(main)
                anti_diagonals.add(anti)
                queen_column[row] = column
                search(row + 1)
                columns.remove(column)
                main_diagonals.remove(main)
                anti_diagonals.remove(anti)

        search(0)
        return answer
```

### Correctness reasoning

Before search(row), every earlier row contains exactly one queen and the occupied-column and diagonal sets exactly describe those queens. A candidate accepted by all three checks cannot attack an earlier queen. The recursion tries every safe column in the current row, so every valid board is reached; undoing all marks restores the invariant for the next branch. Each board corresponds to one unique row-to-column sequence, so no board is duplicated.

### Time and space complexity

The usual search bound is O(n · n!) before output construction. If S boards are returned, constructing them costs O(S · n²). Auxiliary recursion, occupancy arrays, and the row-to-column array use O(n) space, excluding the returned output.

### Edge cases

n = 1 returns one board. n = 2 and n = 3 return no boards. n = 4 returns two boards. The board representation must be copied for every solution so later backtracking cannot mutate earlier output.

### Meaningful alternatives

Bitmask backtracking represents columns and both diagonals as integer masks and reduces constant factors. A permutation-based solution generates column permutations and rejects diagonal conflicts, but it postpones pruning and does more work.

### Common mistakes and recall cues

Offset row - column by n - 1 when indexing an array; row + column already ranges from 0 to 2n - 2. Undo every marker after recursion and copy completed boards. Recall cue: one queen per row, then guard column, difference diagonal, and sum diagonal.
