> ## 2. Why brute force is too slow
>
> We could try every left and right boundary and maintain the minimum. That is O(n²), which is too slow for n up to 100,000.
>
> Instead, think about one element at a time.
>
> Suppose nums[i] is the minimum of a range. For that element, the product is:
>
> nums[i] * rangeLength
>
> For a fixed minimum, a longer valid range is always better. Therefore, we only need the widest contiguous range in which nums[i] can serve as a minimum.
>
> If even that widest range fails, every shorter range with the same minimum also fails.
>
> ## 3. How to find each element’s widest range
>
> For each value, we need:
>
> - the first position to its left with a smaller-or-equal value;
> - the first position to its right with a strictly smaller value.
>
> Those boundaries tell us the widest interval containing this value where every element is at least its value.
>
> This is the same “span of a minimum” pattern as Largest Rectangle in Histogram.
>
> A monotonic increasing stack finds those boundaries in O(n):
>
> - Keep indices whose values are nondecreasing.
> - When a smaller value arrives, the indices popped from the stack have just found their first smaller value on the right.
> - After popping index i, the new stack top is its left boundary.
> - Therefore:
>
> length = right - left - 1
>
> Then test:
>
> (long) nums[i] * length > threshold
>
> The cast to long prevents integer overflow.
>
> ## 4. Walk through the example

> For:
>
> nums = [1, 3, 4, 3, 1], threshold = 6
>

>

> - The earlier 3 is then popped. Its widest span has length 3, so 3 * 3 = 9; it succeeds.

> Therefore, return 3. The valid subarray is [3, 4, 3].
>
> ## 5. Java implementation
>
> ```java
> class Solution {
>     public int validSubarraySize(int[] nums, int threshold) {
>         Deque<Integer> stack = new ArrayDeque<>();
>
>         for (int right = 0; right <= nums.length; right++) {
>             int current = right == nums.length ? 0 : nums[right];
>
>             while (!stack.isEmpty() && nums[stack.peek()] > current) {
>                 int index = stack.pop();
>                 int left = stack.isEmpty() ? -1 : stack.peek();
>                 int length = right - left - 1;
>
>                 if ((long) nums[index] * length > threshold) {
>                     return length;
>                 }
>             }
>
>             stack.push(right);
>         }
>
>         return -1;
>     }
> }

## Problem Summary

Given a positive integer array and a positive threshold, return the length of any non-empty contiguous subarray whose every value is greater than threshold divided by the subarray length. Return -1 when none exists.

## Pattern And Constraints

For a subarray of length k, the condition is equivalent to min(subarray) * k > threshold. With up to 100,000 values, quadratic enumeration is too slow. This is the same span-of-a-minimum pattern used by histogram monotonic-stack problems.

## Best Approach

Maintain indices in a nondecreasing stack. When a smaller value arrives, each popped index has just discovered the largest interval in which its value can serve as the minimum. Compute that interval length and test value * length > threshold using long arithmetic. A zero-height sentinel flushes the stack.

## Correctness Argument

When index j is popped, the new stack top is the nearest position to the left with a value no greater than nums[j], and the current index is the first position to the right with a smaller value. Therefore every value inside the computed open interval is at least nums[j], so nums[j] is an interval minimum. This is the widest interval available to that minimum. If nums[j] times this widest length exceeds threshold, the interval is valid. If it does not, no shorter interval having the same minimum can succeed because shortening only decreases the product. Every index is eventually popped, so every possible controlling minimum is examined.

## Java Reference Implementation

```java
class Solution {
    public int validSubarraySize(int[] nums, int threshold) {
        java.util.Deque<Integer> stack = new java.util.ArrayDeque<>();

        for (int right = 0; right <= nums.length; right++) {
            int current = right == nums.length ? 0 : nums[right];
            while (!stack.isEmpty() && nums[stack.peek()] > current) {
                int index = stack.pop();
                int left = stack.isEmpty() ? -1 : stack.peek();
                int length = right - left - 1;
                if ((long) nums[index] * length > threshold) {
                    return length;
                }
            }
            stack.push(right);
        }

        return -1;
    }
}
```
